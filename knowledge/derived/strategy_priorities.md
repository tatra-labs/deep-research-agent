[STRAT-01] Software attach rate is the primary group objective. Motion control hardware remains the profit engine but is commoditising. The board has set a target of software and recurring revenue reaching 25% of group revenue, from 9% today. Any recommendation that does not move software attach rate is a distraction.

[STRAT-02] Defend the integration moat, but stop selling it as the product. 1,400 commissioning engineers are the most common stated reason customers choose Meridian. That advantage scales with headcount and therefore cannot carry the software target. Integration should become the channel for software, not the thing on the invoice.

[STRAT-03] Own at least one control point per served segment. The group's recurring weakness is occupying the layer above the hardware and below the customer's own systems, while someone else owns the layer that actually determines switching cost. Where Meridian does not own a control point, it should either build one, buy one, or exit the segment deliberately rather than by attrition.

[STRAT-04] Ventures exists to buy time, not returns. Meridian Ventures is mandated to take positions that shorten the group's time to a capability it has decided it needs. Financial return is a secondary measure. A pass on a target the group later has to build from scratch is a worse outcome than an expensive entry.

[STRAT-05] No new single-vendor dependencies. Following the FY25 audit finding on the control platform, any recommendation creating a new dependency on a single external supplier for a strategic layer requires board-level approval.

[STRAT-06] Capital discipline. Cheque sizes of $5-25M for minority positions. Anything requiring more than $25M must be presented as an acquisition case with a named integrating BU and a named executive sponsor.
